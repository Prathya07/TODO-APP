React Native To-Do App with Authentication

A full-stack React Native To-Do application built using React Native CLI, TypeScript, Node.js, Express.js, and MongoDB. The application provides secure user authentication and an intuitive task management experience.

🚀 Features
🔐 User Registration & Login
📝 Create tasks with title, description, date-time, deadline, and priority
✅ Mark tasks as completed
🗑️ Delete tasks
📋 View and manage all tasks with their current status
🔄 Backend API integration using Node.js & Express.js
🍃 MongoDB database for persistent task storage
🎯 Task sorting based on priority, deadline, and time
🏷️ Task categories/tags
🔎 Task filtering and sorting
📱 Responsive and modern mobile UI
🛠️ Tech Stack

Frontend: React Native CLI, TypeScript
Backend: Node.js, Express.js
Database: MongoDB
API: REST API
State Management: React State / Context API
Authentication: Email & Password Authentication

📂 Project Structure

The project is organized into separate frontend and backend modules to maintain clean, scalable, and maintainable code.

🎯 Objective

This project demonstrates practical knowledge of React Native development, TypeScript, authentication, REST API integration, database management, state management, and mobile UI/UX design.

Built as part of a React Native Developer Assignment to demonstrate full-stack mobile application development skills.
